# SIT725 Task 2.2P - Express Web Server

This project demonstrates a basic Express web server. It serves a web page from the public folder and provides a GET endpoint that adds two numbers on the server.

## Run the Application

Install the dependencies: `npm install`

Start the server: `npm start`

Open the web page: <http://localhost:3000>

Test the add-two-numbers endpoint:

<http://localhost:3000/addTwoNumbers?number1=5&number2=7>

Example result:

`{"number1":5,"number2":7,"result":12}`
